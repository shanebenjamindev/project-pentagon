Viết MỘT file `index.html` trong thư mục hiện tại: landing page giới thiệu hệ thống "Pentagon". Viết bằng tiếng Việt có dấu, giọng gọn, rõ, thân thiện.

## Yêu cầu kỹ thuật
- Một file HTML tự chứa: CSS và JS inline, KHÔNG tải gì từ mạng (không CDN, không Google Fonts). Dùng font hệ thống: -apple-system, "Segoe UI", Roboto, sans-serif; code dùng ui-monospace, Menlo.
- Logo: `<img src="mark.png">` (file đã có sẵn cạnh index.html, ảnh 160x138 nền trong suốt). Cũng dùng làm favicon.
- `<title>Pentagon</title>`, `lang="vi"`, meta viewport.
- Bảng màu (đặt trong :root làm biến CSS) lấy từ web app của Pentagon:
  Sáng: --bg:#f6f7f9; --panel:#fff; --line:#e3e6ea; --text:#1d2228; --muted:#69727d; --soft:#f0f2f5; --accent:#3b6fd8; --ok:#1f9d55; --warn:#c58a00; --bad:#d64545; --run:#0e8fa6; --mgr:#8a4fd1
  Tối: --bg:#121417; --panel:#1a1d21; --line:#2b3036; --text:#e6e8eb; --muted:#9099a3; --soft:#22262b; --accent:#6f9bff; --ok:#3ccf7f; --warn:#f0b429; --bad:#ff6b6b; --run:#3cc7de; --mgr:#b98aff
  Dark mode theo `@media (prefers-color-scheme: dark)`; thêm nút chuyển sáng/tối ở thanh trên (lưu lựa chọn vào localStorage, bọc try/catch).
  Màu --mgr (tím) dùng cho "AI quản lý", --accent (xanh) cho "worker"/nút chính, --ok cho trạng thái xong.
- Responsive: đẹp ở 375px (lề 16px, không cuộn ngang) đến màn hình rộng (nội dung max ~1100px).
- Thiết kế hiện đại, sạch, có chiều sâu vừa phải (bo góc, viền mảnh, bóng nhẹ, gradient nhẹ ở hero). Không lạm dụng emoji. Sơ đồ vẽ bằng HTML/CSS hoặc SVG inline.
- Khối code có nút "Sao chép" (navigator.clipboard, có fallback).
- Thanh điều hướng dính trên cùng với link neo tới các mục; cuộn mượt.
- KHÔNG bịa số liệu, khách hàng, lời chứng thực, giá cả, link tải. Chỉ dùng thông tin dưới đây.

## Các mục nên có (theo thứ tự)
1. Hero: tên "Pentagon", khẩu hiệu "1 người giao việc, 1 AI quản lý, nhiều AI làm". Mô tả: dùng gói thuê bao sẵn có (Claude Pro/Team, ChatGPT Plus/Team, Google AI Pro…) qua các CLI chính chủ, không cần API key. Hai nút: "Bắt đầu" (neo tới mục bắt đầu nhanh) và "Xem quy trình".
2. Cách hoạt động — sơ đồ luồng:
   Bạn ──/giao task──▶ Claude Code (AI quản lý, đọc CLAUDE.md)
     ├─ tối ưu yêu cầu → tasks/<id>/brief.md
     ├─ chia việc → tasks/<id>/plan.md
     ├─ bin/ask claude ▶ claude-main → claude-2 → … (tự chuyển khi hết hạn mức)
     ├─ bin/ask codex ▶ codex-main → codex-2 → …
     ├─ bin/ask gemini ▶ gemini-main → …
     └─ kiểm tra, tổng hợp → tasks/<id>/final.md
3. Quy trình 6 bước của AI quản lý (dạng timeline/thẻ đánh số):
   1 Tiếp nhận — tạo thư mục task, ghi yêu cầu gốc nguyên văn vào brief.md.
   2 Tối ưu yêu cầu — viết lại rõ mục tiêu, đầu ra, ràng buộc, tiêu chí "xong"; tự giả định hợp lý và ghi rõ, chỉ hỏi lại khi thật sự thiếu thông tin.
   3 Lập kế hoạch — chia việc con trong plan.md: worker phụ trách, đầu vào, đầu ra, cỡ việc. Việc đơn giản thì quản lý tự làm luôn.
   4 Giao việc — mỗi việc con gửi kèm đủ ngữ cảnh (worker không thấy cuộc trò chuyện).
   5 Kiểm tra — đọc kết quả; việc quan trọng thì nhờ worker KHÁC loại kiểm tra chéo; sai thì giao lại kèm nhận xét (tối đa 2 lần) rồi tự sửa.
   6 Tổng hợp — viết final.md, báo kết quả chính, ai làm phần nào, phần nào chưa chắc chắn.
4. Đội worker — 3 thẻ:
   claude: suy luận sâu, lập kế hoạch, viết/sửa code khó, review, viết nội dung tinh tế.
   codex: viết code, sửa lỗi, refactor, viết và chạy test, thao tác trên repo.
   gemini: đọc tài liệu/codebase rất dài, tra cứu và tổng hợp, xử lý ảnh/video.
5. Tính năng nổi bật (lưới thẻ):
   - Xoay vòng tài khoản: mỗi công cụ có thể có nhiều tài khoản; tài khoản đầu hết hạn mức thì tự chuyển sang tài khoản kế tiếp, và tài khoản sau làm tiếp phần dở, không làm lại. Thêm bao nhiêu tài khoản cũng được (một dòng trong config/workers.conf + bin/login <tên>); mỗi tài khoản lưu đăng nhập trong thư mục riêng nên không đè lên nhau.
   - Chọn model theo cỡ việc: -s nho | vua | lon (config/models.conf). Việc nhỏ dùng model nhỏ, nhanh, đỡ tốn hạn mức; việc khó dùng model mạnh. Ví dụ Claude: haiku / sonnet / opus.
   - An toàn mặc định: worker chỉ được đọc; phải thêm -w thì mới sửa được file, và chỉ trong thư mục -C chỉ định.
   - Một worker hoặc song song: mặc định giao lần lượt cho một worker phù hợp nhất; chỉ chia nhiều worker cùng lúc khi chủ chọn "song song".
   - Theo dõi tiến độ: bin/status (terminal, -w tự làm mới) hoặc web dashboard; thấy bước hiện tại trong 6 bước, việc con nào xong, worker nào đang chạy và bao lâu.
   - Mọi thứ là file: mỗi task một thư mục tasks/<id>/ gồm brief.md, plan.md, status, results/, log.txt, final.md — dễ đọc lại, dễ đồng bộ bằng git.
6. Web app (bin/dashboard --open → http://127.0.0.1:8765):
   - Giao task bằng nút "+ Giao task": quản lý tự quyết, chờ bạn duyệt kế hoạch, hoặc làm luôn.
   - Trò chuyện với AI quản lý của từng task: thấy từng bước nó làm, trả lời câu hỏi, bấm "Đồng ý, tiến hành", nhắn thêm yêu cầu sửa.
   - Dừng quản lý, huỷ worker đang chạy, huỷ task, đánh dấu xong.
   - Tab trình duyệt hiện số task đang chờ bạn, vd "(1) Pentagon".
   - Quản lý chạy nền, mỗi task một phiên riêng nên nhớ ngữ cảnh; đóng trình duyệt không làm dừng quản lý.
   - Bảo mật: chỉ nghe trên 127.0.0.1, chặn yêu cầu từ trang web lạ; khi chạy nền quản lý chỉ dùng một số lệnh an toàn (mở rộng trong config/manager.conf). Không mở cổng này ra mạng ngoài.
   Có thể vẽ một "mockup" nhỏ bằng HTML/CSS minh hoạ danh sách task (vd thẻ task với thanh 6 bước, nhãn "đang chạy: codex-main 1m20s", "xong") — ghi chú rõ là minh hoạ.
7. Bắt đầu nhanh (khối code có nút sao chép):
   cd Pentagon
   bin/setup              # kiểm tra mọi thứ đã sẵn sàng chưa (máy mới: bash bin/setup --all để cài CLI + đăng nhập)
   claude                 # mở AI quản lý
   Rồi trong Claude Code gõ: /giao <mô tả task>
   Ví dụ gọi worker trực tiếp:
   bin/ask codex -s nho "Viết hàm Python kiểm tra số nguyên tố, kèm test"
   bin/ask claude -t tasks/<id> "Review đoạn code trong results/codex-main-*.md"
   bin/ask codex -w -C ~/du-an-cua-toi "Sửa lỗi trong file app.py"
   Yêu cầu: macOS hoặc Linux (Windows dùng WSL), Node.js/npm, python3, các gói thuê bao đã có.
8. Nên chạy ở đâu (bảng): Pentagon chạy trên máy của bạn vì bin/ask gọi các CLI claude/codex/gemini đã đăng nhập trên máy.
   VSCode (extension Claude Code) ✅ — vừa giao task vừa xem/sửa file trong tasks/
   App Claude desktop → tab Code ✅ — giao task nhanh, đọc kết quả
   Terminal: claude ✅ — nhẹ nhất, hợp task dài
   claude.ai/code (web) ❌ — chạy trên cloud, không có CLI và tài khoản của bạn
   Chat trên claude.ai ❌ — không chạy được lệnh
   Ghi chú: máy phải bật suốt lúc task chạy.
9. Câu hỏi thường gặp (dùng <details>): Có cần API key không? (không, dùng gói thuê bao qua CLI chính chủ). Hết hạn mức thì sao? (tự chuyển tài khoản, làm tiếp phần dở; hết mọi tài khoản thì chuyển sang công cụ khác, không còn cách thì tạm dừng và tự làm tiếp khi có hạn mức). Dùng nhiều máy được không? (được, nhưng chung hạn mức; không copy thư mục đăng nhập sang máy khác — đăng nhập lại). Chỉ dùng tài khoản của bạn hoặc ghế trong gói Team của bạn.
10. Footer: "Pentagon — đội AI làm việc cho bạn, chạy trên máy của bạn." Không thêm link ngoài.

## Khi xong
Chỉ tạo/sửa `index.html` trong thư mục hiện tại. Trả lời ngắn: các mục đã làm, kích thước file, điểm cần lưu ý.
